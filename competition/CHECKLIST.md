# Competition readiness checklist

- [ ] Confirm actual event date; screenshot event date and registration deadline conflict
- [ ] Read full organizer rules; check whether prebuilt projects are eligible
- [ ] Confirm team membership and single team account
- [ ] Declare any pre-trained model before use
- [ ] Obtain official train/test/sample files and metric
- [ ] Select appropriate temporal/group/stratified validation
- [ ] Run baseline and save metric, seed, environment and artifact
- [ ] Verify submission column names, row order, IDs and values
- [ ] Respect submission-per-hour limit
- [ ] Run clean notebook from top to bottom
- [ ] Record actual leaderboard results without overstating them
- [ ] Prepare backup screenshots for live demo
- [ ] Keep competition data and credentials out of GitHub
- [ ] Present documented limitations and provenance of benchmark data
